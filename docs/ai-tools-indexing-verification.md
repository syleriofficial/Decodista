## Verifiable technical checks (no private account needed)

1. Request `/robots.txt`: check it contains `Sitemap: https://decodista.com/sitemap.xml`, allows the research guides and keeps `/admin` excluded.
2. Request `/sitemap.xml`: check each of the two full guide URLs appears exactly once, and the noindex starter pages are absent as individual `<loc>` entries.
3. Request both guide pages: ensure HTTP 200, a unique canonical inside `<head>`, no `noindex`, original source links and the current editorial-reviewed date.
4. Request `/` and `/ai`: each must have text-anchor HTML links to both guides; no JavaScript-only click targets or linking through a noindex intermediary.
5. Request the starter directory, generic comparison, provider profile, pricing, alternatives and thin guide archive: verify their `noindex` metadata has not changed.
6. Run the existing automated production workflow. It tests live HTTP, links, metadata, sitemap and negative-indexing boundaries. **It does not emulate Googlebot or certify Google's index.**

## Search Console owner steps

The connected GSC Wizard reporting tool currently returns `payment_required`. This says nothing about a particular page's actual performance, and cannot be substituted with estimated clicks or search rankings.

Owners with direct access to [Google Search Console](https://search.google.com/search-console) can:

1. Choose the verified `decodista.com` property and open **Sitemaps**. Submit `https://decodista.com/sitemap.xml` if not already submitted. Google may fetch it later; submission does not guarantee indexing.
2. Use **URL Inspection** on each guide URL. Record whether the page is indexed, whether the user-declared and Google-selected canonicals match, the last crawl status, and any discovered accessibility/indexing issue. **Request indexing** when supported, after ensuring page quality and server availability.
3. In **Performance > Search results**, use the Pages filter for those two URLs. Record genuine **clicks, impressions, CTR and average position** over a stated period. New URLs may have no data; do not treat missing data as confirmed deindexing.
4. Inspect the **Pages / indexing** report for excluded URLs and separate intentional noindex from errors. A `site:` search is only an informal discovery check, not an authoritative URL Inspection result.

Google documentation:
- https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap
- https://developers.google.com/search/docs/crawling-indexing/links-crawlable
- https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls
