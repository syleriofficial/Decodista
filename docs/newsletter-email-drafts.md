**Issue 01 — November 1, 2026**

This week brought changes to browser security, private information in Chrome and how AI developers describe their data and model policies. Here's the concise version.

**1. Chrome begins rolling out Gmail-based enhanced autofill**

Google announced a feature that can use information from Gmail for smarter form suggestions for eligible users. Availability is limited; review the privacy settings if it appears for you.

**2. Apple publishes security updates for several operating systems**

The update offered depends on your device and software branch. Back up important data and check the built-in Software Update screen.

**3. Firefox 159 fixes multiple security vulnerabilities**

Mozilla released security fixes. Firefox users should check the official update available for their installation.

**4. A shared AI-training preference signal is proposed**

OpenAI announced plans to support a more consistent way for websites to express AI-training preferences. The change was announced, not yet implemented everywhere.

**5. OpenAI updates its public Model Spec**

The specification describes intended AI behavior and trade-offs. It isn't a guarantee of what every AI response will do.
